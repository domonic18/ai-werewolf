# 设计规范 v2 ·「夜席 NOCTURNE」

> 目标：把原型从「AI 生成的深色卡片堆」改造成**可信的、有作者感的**移动端游戏界面。
> 方法论来自 ui-ux-pro-max 设计技能（Style Selection / Typography / Accessibility 三条优先线），
> 结合狼人杀这一题材的既有视觉语言（桌游、纸质角色牌、油灯、档案、月相）。

## 为什么 v1 一眼像 AI

| 症状 | v1 的做法 | v2 的对策 |
|---|---|---|
| emoji 当图标 | 🐺🔮🧪🙋 混用在头像、角色、按钮 | 全部换成自绘 1.5px 描边 SVG；人物用插画头像 |
| 多彩渐变滥用 | 金色→紫色 158° 斜切渐变铺满 Hero、卡片、按钮 | 只用单色压暗（scrim）与 8% 同色底，禁双色斜切渐变 |
| 圆角/胶囊通货膨胀 | 24px 卡、999px 药丸、毛玻璃 | 圆角收到 4/8/12/16 四档，胶囊只给筛选与徽标 |
| 纯色紫蓝 + 霓虹光晕 | `#a78bfa` 光斑 + 阴影外发光 | 夜间桌面的低饱和暖灰，唯一强调色是旧黄铜 |
| 信息层级全靠加亮 | 所有标题 800 字重、全是白字 | 衬线标题 + 无衬线正文 + 单色分层，靠字号与留白拉层级 |
| 假数据撑场面 | 「128 局 · 1,204 人在看」 | 只显示服务端真实数字，空就空着 |

## 概念

**夜席**：一张桌、一盏灯、六张扣着的牌。界面像**桌游的纸质道具**，不像 SaaS 面板。

三条视觉原则：

1. **纸与灯**：底色是暖黑（不是纯黑、不是蓝黑），文字是陈纸白；光只从一侧来（顶部单光源）。
2. **少而准的强调色**：全站只有一个「金」= 旧黄铜 `--brass`，危险才用 `--ember`；其余靠明度差。
3. **手作痕迹**：1px 发丝线、颗粒噪点、编号与刻度——让画面有印刷品的密度，不像自动生成的渐变块。

## 字体（v2.1 修订）

v2 初版标题用了宋体，实际在高分屏小字号下笔画发虚、字重不匀，且与无衬线正文气质打架。
v2.1 起**标题改用系统无衬线**，靠字重与负字距拉层级；衬线只保留给品牌字与结算判定这类仪式性大字。

| 角色 | 字体栈 | 用法 |
|---|---|---|
| UI / Display `--font-ui` | `"PingFang SC",-apple-system,BlinkMacSystemFont,"Noto Sans SC","Helvetica Neue","Segoe UI",Arial,sans-serif` | 全站标题、正文、按钮、表单 |
| Mark `--font-mark` | `"Songti SC","Noto Serif SC","Source Han Serif SC",Georgia,serif` | 只给品牌「狼」字、结算判定 |
| Mono `--font-mono` | `ui-monospace,"SF Mono",SFMono-Regular,Menlo,monospace` | 对局编号、房间码、票数等数字 |

排版规则：

- 标题：700 字重 + 负字距（-0.01 ~ -0.02em），行高 1.22–1.28；不再用 600 + 正字距
- 正文：400/500，13px、行高 1.6；列表项 12.5；辅助文案不小于 10.5
- 标签：10px、大写拉丁、字距 +0.14em，颜色 `--faint`
- 数字：一律 `font-variant-numeric: tabular-nums`，避免跳动
- 全局 `letter-spacing: 0.01em` + `font-kerning: normal`，中文不挤在一起

## 形状与层次

- 圆角：`--r-sm 4px`（徽标）/`--r-md 8px`（输入、小卡）/`--r-lg 12px`（卡片）/`--r-xl 16px`（容器）
- 描边：1px 发丝线为主，交互件才用 `--line-strong`；不用外发光阴影
- 阴影：只在浮层（提示条、底部操作区）用 `0 8px 24px rgba(0,0,0,.5)`
- 质感：页面顶部一层 6% 的单光源渐变 + 全页 3% 颗粒噪点（内联 SVG `feTurbulence`），纯 CSS，无图片请求

## 图标

- 统一 `viewBox="0 0 24 24"`、`stroke-width 1.5`、圆头圆角、`currentColor`
- 尺寸 16 / 18 / 20 / 24，只用几何构造，不描细节（16px 下也要清楚）
- 角色徽记（狼 / 眼 / 药瓶 / 猎枪 / 盾 / 面具 / 杖 / 冠 / 月 / 村民）用简短字形，不用 emoji
- 图标一律配文字或 `aria-label`，不做「只有图标的裸按钮」（返回键例外，有 `aria-label`）

## 图像

| 资产 | 规格 | 用途 |
|---|---|---|
| `hero-night.jpg` | 1536×1024 生成图 | 首页 Hero 顶部主视觉（狼影 / 月 / 雾），底部压暗接纸面 |
| AI 头像 | 内联 SVG（`Avatar.tsx`） | 五位 AI 玩家的矢量面孔，见下节 |
| 真人头像 | 内联 SVG 剪影 + 黄铜描边 | 玩家自己 |

图像使用规则：拍照/生成图只用于场景（首页主视觉），人物一律矢量绘制；不用彩色滤镜、不做圆角以外的装饰。

### 头像规范（v2.1 修订）

写实人物照片在小尺寸下彼此难以区分，且自带「AI 生成」气质，已全部废弃。头像改为**矢量面孔**，
靠三重要素保证 20px 下也能认人：

1. **底色**：每位 AI 一个固定低饱和底色（板岩 / 暖棕 / 青蓝 / 橄榄 / 紫褐），是最大的识别信号
2. **剪影**：发型或帽子必须是明确形状——墨镜男、丸子头、长直发、卷发云、礼帽
3. **配件**：墨镜、细框眼镜、耳环、耳钉、张嘴笑；其余五官只保留两个点 + 一条短弧嘴

实现约束：`Avatar.tsx` 里每个角色一段 `FaceSpec`（底色 / 衣服 / 头发 / 肤色 / 发型路径 / 配件），
只画平面色块，不描细节、不用渐变；超过 5 位 AI 时按座位号轮流复用五种面孔，不退化成字母块。

## 动效

- 时长 160–240ms，`cubic-bezier(.2,.8,.2,1)`；只动 `opacity` / `transform`
- 页面切换：淡入 + 8px 上移（保留）
- 按钮按下：`scale(.98)`，不做回弹
- 尊重 `prefers-reduced-motion`：全部动画降为 0

## 夜幕（夜晚过场，v1.9）

夜里原本只有一行口令和等待，狼人杀一半的氛围就没了。夜幕是全站唯一「全屏独占」的时刻，
规则与其他页面不同，必须单列：

- **构图**：暖黑满屏压暗 → 月盘居中偏上（带内阴影的圆盘，不是发光球）→ 口令一次只落一句。
  不做彩色光晕、不做粒子、不做星空贴图；氛围靠留白与低频。
- **字体**：口令用 `--font-mark`（衬线）大字 + 0.16em 字距。这是全站仅有的两处「仪式性衬线」之一
  （另一处是结算判定），不许扩散到普通标题。
- **节奏**：首句前 650ms 静场；句间 1100ms；最短停留 1100ms（防止「闪一下黑屏」）；
  上限 9s（AI 思考时不长期盖屏，交给夜幕条接管）。
- **永不阻塞**：真人一旦有夜间决策（验人 / 用药 / 狼刀），过场立刻让位——动画不许和玩家的回合抢屏幕。
- **声音**：程序化合成（55Hz + 82.5Hz 低频 + 带通噪声），不引入音频文件；默认开、可一键静音并记在本机；
  浏览器拒绝自动播放时静默降级。
- **可跳过**：右下角「跳过」；跳过与演完都记进 `watchedRound`，同一夜不重播。
- **落地**：`client/src/components/NightCurtain.tsx` + `client/src/lib/night.ts`（时序与门控）+ `client/src/lib/sound.ts`。

## 文案语气

短句、克制、有判断，不用感叹号，不用「✨ 系统已为你…」这类运营腔。
例：`5 个会说谎的 AI，等你入席` / `今晚的牌，由你定` / `没有人在看这局`。

## 落地检查清单

- [ ] 全站无 emoji 字符（含服务端下发的选项文案）
- [ ] 无双色斜切渐变、无外发光、无毛玻璃
- [ ] 强调色只出现于主按钮 / 选中 / 关键数字
- [ ] 所有可点区域 ≥ 44×44 或带透明扩展热区
- [ ] 图标为 SVG，且与文字同色系
- [ ] 空态有文案，加载态有骨架，错误态贴近出错位置
- [ ] 动画不阻塞决策：任何过场遇到「该玩家操作」都必须立刻让位
- [ ] 会发声的地方一定有静音入口，且选择被记住
