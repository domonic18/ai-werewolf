# AI 人格与推理差异化

> 目标：场上五六个 AI 不能是「同一个高手穿了六件衣服」。
> 本文说明三件事：**AI 知道什么**（信息边界）、**AI 是谁**（人格参数）、**差异怎么落到 prompt 上**（实现）。

## 一、信息边界：AI 只知道自己的身份

| 谁知道什么 | 内容 |
|---|---|
| 所有人 | 公开信息：第几天、谁还活着、谁被放逐、公开发言、遗言、投票结果、昨夜死讯（不翻牌） |
| 自己 | 自己的身份与技能状态（女巫剩几瓶药、预言家验过谁、守卫上夜守了谁） |
| 狼人额外 | 自己的狼队友都有谁、谁已经出局 |
| 任何人 | **不知道**别人的身份；死亡未翻牌的人，身份依然不可见（`revealRole=false` 时显示「身份未公开」） |

三条实现约束（`tests/ai-persona.test.ts` 有对应断言）：

1. prompt 只由 `publicBrief()` + `privateBrief()` 拼成，`privateBrief()` 只读自己的字段；
2. 出局者身份只在 `revealRole=true`（被放逐翻牌）时才写进公开日志；
3. 观战投影（上帝视角）与 AI 视图是两个函数，禁止合并。

## 二、人格参数

每个角色除了名字与一句话性格，还带一组 **traits**：

| 参数 | 范围 | 作用 |
|---|---|---|
| `skill` | 0~1 | 牌感。决定**能看到多少条发言记录**、**允许推理几层**、内心记忆保留几条 |
| `style` | logic / emotion / intuition / chaos / probe | 推理方式与固有短板 |
| `talk` | 0~1 | 话量：决定要求模型输出的字数区间（15~40 / 40~80 / 80~120） |
| `push` | 0~1 | 攻击性：是否主动点人、归票 |
| `suggestibility` | 0~1 | 易受影响程度：是否容易被带节奏改口 |
| `mood` | calm / sharp / tilted / lazy | 每局随机，同一角色不同局表现不同 |

开局时 `skill` 还会做 ±0.08 抖动，`mood` 重新抽取 —— 所以「阿岚今天是不是在线」是随机的。

## 三、差异怎么落到 prompt

`personaCard()` 把 traits 翻译成**行为描述**（不给模型看数字，避免它「按分数表演」）：

```
你的名字：老K（3 号位）。你的性格：沉稳老练，说话短促，喜欢抓别人话里的逻辑漏洞。
牌感：熟手。你能记住明显的矛盾和谁站过谁的边，细节会漏一些。推理一两层就够，别把话说得过于严密。
思维方式：你习惯先摆事实再下结论，会算票、会追问细节。
你的短板（真实存在，不要掩饰，也不要自己点破）：过度自信：一旦认定就很难改，容易把巧合当逻辑。
说话与行动：话少，能一句说完不说两句；攻击性强，敢点人、敢归票；不太受人影响。
本局状态：头脑格外清醒，抓细节比平时准。
```

四处硬机制（不只是提示词里写「你要像新手」）：

1. **记忆窗口**：`publicLog` 只喂最近 `8 + skill×16` 条（8~24）。新手真的看不到十几轮前的矛盾。
2. **推理深度**：牌感档位直接写明「别做复杂推理，可凭感觉/跟风/记错」，老玩家才允许「多步推理」。
3. **发言长度**：`talk` 决定字数区间（15~40 / 40~80 / 80~120），场上有短句也有长文。
4. **温度**：混沌 +0.12、逻辑 −0.06，`tilted` +0.08、`lazy` −0.05，最终夹在 0.6~1.1。

内部记忆（`thoughts`）保留条数同样随牌感缩放（2~6 条），低牌感角色更容易「忘了自己上次怎么站的边」。

## 五、修改指引

- 调整某个人：只改 `src/game/roles.ts` 的 `traits`，不要写新的分支逻辑
- 新增角色：在 `AI_CAST` 里加一条（12 人局最多用 11 个 AI），并确保 `style` 覆盖到需要的类型
- 新增推理档位：改 `ai-player.ts` 的 `skillTier()`，同时补一条 prompt 断言测试
- 改动身份可见性：先看 `docs/standard/SECURITY.md` 第二节，再动 `revealRole` / `publicBrief`
