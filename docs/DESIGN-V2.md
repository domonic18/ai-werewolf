# 设计规范 v2 ·「夜席 NOCTURNE」

> 目标：把原型从「AI 生成的深色卡片堆」改造成**可信的、有作者感的**移动端游戏界面。
> 方法论来自 ui-ux-pro-max 设计技能（Style Selection / Typography / Accessibility 三条优先线），
> 结合狼人杀这一题材的既有视觉语言（桌游、纸质角色牌、油灯、档案、月相）。

## 为什么 v1 一眼像 AI

| 症状 | v1 的做法 | v2 的对策 |
|---|---|---|
| emoji 当图标 | 🐺🔮🧪🙋 混用在头像、角色、按钮 | 全部换成自绘 1.5px 描边 SVG；人物用插画头像 |
| 多彩渐变滥用 | 金色→紫色 158° 斜切渐变铺满 Hero、卡片、按钮 | 只用单色压暗（scrim）与 8% 同色底，禁双色斜切渐变 |
| 圆角/胶囊通货膨胀 | 24px 卡、999px 药丸、毛玻璃 | 圆角收到 4/8/12/16 四档，胶囊只给筛选与徽标 |
| 纯色紫蓝 + 霓虹光晕 | `#a78bfa` 光斑 + 阴影外发光 | 夜间桌面的低饱和暖灰，唯一强调色是旧黄铜 |
| 信息层级全靠加亮 | 所有标题 800 字重、全是白字 | 衬线标题 + 无衬线正文 + 单色分层，靠字号与留白拉层级 |
| 假数据撑场面 | 「128 局 · 1,204 人在看」 | 只显示服务端真实数字，空就空着 |

## 概念

**夜席**：一张桌、一盏灯、六张扣着的牌。界面像**桌游的纸质道具**，不像 SaaS 面板。

三条视觉原则：

1. **纸与灯**：底色是暖黑（不是纯黑、不是蓝黑），文字是陈纸白；光只从一侧来（顶部单光源）。
2. **少而准的强调色**：全站只有一个「金」= 旧黄铜 `--brass`，危险才用 `--ember`；其余靠明度差。
3. **手作痕迹**：1px 发丝线、颗粒噪点、编号与刻度——让画面有印刷品的密度，不像自动生成的渐变块。

## 色板（语义 token）

| Token | 值 | 用途 |
|---|---|---|
| `--ink-900` | `#0A0A0B` | 页面底 |
| `--ink-850` | `#0E0E10` | 分区底 |
| `--ink-800` | `#131315` | 卡片 |
| `--ink-700` | `#191A1D` | 卡内浮层 / 输入框 |
| `--line` | `rgba(255,255,255,0.09)` | 发丝线 |
| `--line-strong` | `rgba(255,255,255,0.16)` | 可交互描边 |
| `--bone` | `#EDE7DA` | 主文字（陈纸白，非纯白） |
| `--ash` | `#A6A199` | 次要文字 |
| `--smoke` | `#767268` | 辅助 / 占位 |
| `--brass` | `#B99A63` | 唯一强调色：主按钮、选中、关键数字 |
| `--brass-dim` | `#8A7444` | 强调色的暗部 |
| `--ember` | `#C0523F` | 狼人 / 危险 / 出局 |
| `--sage` | `#7C9483` | 好人 / 存活 / 通过 |
| `--steel` | `#71849B` | 神职 / 夜间信息 |

对比度：`--bone` on `--ink-800` = 12.6:1，`--ash` on `--ink-800` = 6.4:1，`--brass` on `--ink-900` = 6.1:1，均过 WCAG AA。

## 字体

| 角色 | 字体栈 | 用法 |
|---|---|---|
| Display `--font-display` | `"Songti SC","Noto Serif SC","Source Han Serif SC",Georgia,serif` | 页面主标题、结算判定、座位号 |
| UI `--font-ui` | `-apple-system,"PingFang SC","Helvetica Neue",Arial,sans-serif` | 正文、按钮、表单 |
| Mono `--font-mono` | `ui-monospace,"SF Mono",Menlo,monospace` | 对局编号、房间码、票数等数字 |

字号阶梯：10 / 11 / 12 / 13 / 15 / 17 / 21 / 26（正文不小于 12，主标题用衬线 + 600，不再全站 800）。
数字统一 `font-variant-numeric: tabular-nums`。

## 形状与层次

- 圆角：`--r-sm 4px`（徽标）/`--r-md 8px`（输入、小卡）/`--r-lg 12px`（卡片）/`--r-xl 16px`（容器）
- 描边：1px 发丝线为主，交互件才用 `--line-strong`；不用外发光阴影
- 阴影：只在浮层（提示条、底部操作区）用 `0 8px 24px rgba(0,0,0,.5)`
- 质感：页面顶部一层 6% 的单光源渐变 + 全页 3% 颗粒噪点（内联 SVG `feTurbulence`），纯 CSS，无图片请求

## 图标

- 统一 `viewBox="0 0 24 24"`、`stroke-width 1.5`、圆头圆角、`currentColor`
- 尺寸 16 / 18 / 20 / 24，只用几何构造，不描细节（16px 下也要清楚）
- 角色徽记（狼 / 眼 / 药瓶 / 猎枪 / 盾 / 面具 / 杖 / 冠 / 月 / 村民）用简短字形，不用 emoji
- 图标一律配文字或 `aria-label`，不做「只有图标的裸按钮」（返回键例外，有 `aria-label`）

## 图像

| 资产 | 规格 | 用途 |
|---|---|---|
| `hero-night.jpg` | 1536×1024 生成图 | 首页 Hero 顶部主视觉（狼影 / 月 / 雾），顶部压暗后叠字 |
| `agent-*.jpg` ×5 | 1024×1024 生成图 | 五个 AI 玩家头像，统一侧光、颗粒、低饱和 |
| 人物默认头像 | SVG 剪影 | 真人玩家与自己 |

图像使用规则：一律加暗角与顶部 scrim 保证文字对比；不用彩色滤镜；不用圆角以外的装饰。

## 动效

- 时长 160–240ms，`cubic-bezier(.2,.8,.2,1)`；只动 `opacity` / `transform`
- 页面切换：淡入 + 8px 上移（保留）
- 按钮按下：`scale(.98)`，不做回弹
- 尊重 `prefers-reduced-motion`：全部动画降为 0

## 文案语气

短句、克制、有判断，不用感叹号，不用「✨ 系统已为你…」这类运营腔。
例：`5 个会说谎的 AI，等你入席` / `今晚的牌，由你定` / `没有人在看这局`。

## 落地检查清单

- [ ] 全站无 emoji 字符（含服务端下发的选项文案）
- [ ] 无双色斜切渐变、无外发光、无毛玻璃
- [ ] 强调色只出现于主按钮 / 选中 / 关键数字
- [ ] 所有可点区域 ≥ 44×44 或带透明扩展热区
- [ ] 图标为 SVG，且与文字同色系
- [ ] 空态有文案，加载态有骨架，错误态贴近出错位置
